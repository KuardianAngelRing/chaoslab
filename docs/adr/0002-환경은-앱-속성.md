# ADR-0002: 실행 환경(k3s/EKS)은 유저에게 묻지 않는다 — 앱의 속성이다

- 날짜: 2026-07-29
- 상태: 승인 (시웅 결정)
- 작성: 시웅 + Claude (grill 세션)

## 맥락

실험 시작 시 "k3s인가 EKS인가"를 유저에게 물을지 논의. 구는 새 프로젝트 모달에 Kubernetes/EKS 토글이 있었으나 비활성 장식이었음.

## 결정

- 환경은 **앱이 등록/배포되는 시점에 정해지는 앱의 속성**. 실험 시작 플로우에서는 묻지 않고 앱 카드에 배지(k3s·온프레미스 / EKS·클라우드)로만 표시한다.
- 백엔드가 환경별로 갈리는 것은 앱 속성 기반으로 뒤에서 라우팅한다.

## 결과

- 새 실험 위저드 step 1은 "앱 선택"이며 환경 질문이 없다 (2026-07-29 목업 구현됨).
- 환경 분기가 유저에게 드러나는 자리는 **앱 등록 플로우**로 이동한다. 등록의 분기 기준(환경 vs 소스 형태)은 ADR-0003에서 다룬다.
- App 모델에 클러스터/환경 필드 추가 필요 (백로그 — 현재 목업은 이름 기반 모의 배지).
