# ADR-0001: 구(ChaosPilot/agent)를 신(chaoslab)에 흡수한다

- 날짜: 2026-07-29
- 상태: 승인 (시웅 결정)
- 작성: 시웅 + Claude (grill 세션)

## 맥락

온프레미스 ChaosPilot(agent 레포, "구")과 클라우드 chaoslab("신")이 별개 대시보드로 존재.
둘 다 UX 문제가 많고, 구의 실험 로직(AI 후보 제안 → 승인 → 실행 → 개선 루프)을 팀 통합 허브로 옮겨야 함.

## 결정

- 구를 신에 흡수한다. 흡수 과정은 사실상 전면 재설계 수준으로 진행.
- 구의 '프로젝트' 개념(manifest+실험+보고 수명주기 컨테이너)은 신에 층으로 심지 않고 **신의 'App'(SUT) 개념에 흡수**한다.
- 작업은 포크 `silverttthin/chaoslab`에서, 실코드 미연결 목업(stub/seed)으로 증분 진행 → 팀 회의에서 워크플로우 비교.

## 결과

- 유저 플로우: 앱 등록(Apps) → 실험 시작(카오스 탭) → 실험 상세(진행·판정·개선·보고).
- 구의 화면·개념 중 승격/처형 대상은 해체 분석으로 결정 (예: healthcheck_path 승격, env_text·EKS 토글 장식 제거, 에이전트 내부명 노출 제거).
