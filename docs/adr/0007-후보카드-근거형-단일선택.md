# ADR-0007: 후보 카드는 근거형, 선택은 단일

- 날짜: 2026-07-29
- 상태: 승인 (시웅 결정, grill 세션)

## 결정

- **카드 정보량 = 근거형**: 제목 + 장애 유형 배지 + 대상 워크로드 + **가설 한 줄** + 예상 영향.
  유저가 "왜 이 실험인지" 알고 골라야 승인 게이트가 형식적 클릭이 아니라 판단이 된다 (Human-in-the-loop 원칙).
  YAML 미리보기는 제외 — YAML은 선택 *후* 구체화 단계의 산물이라 시점이 안 맞음 (구도 선택된 후보만 YAML 생성).
- **선택 = 단일**: Claude Code 패턴 그대로. 마지막 선택지는 "직접 입력"(자유 텍스트, ADR-0006).
- 구의 복수 선택(후보 5 중 최대 3 연쇄 실행)은 보류 — "실험 묶음" 상위 개념이 신 데이터 모델에 없어
  즉시 요구되는 비용이 큼. 데이터 모델 논의 후 증분으로 재검토 (백로그).
- 단일 선택 채택에 따라 고급 설정의 "최대 실행 수" 입력은 제거한다 (후보 수·개선 반복만 유지).

## 결과

- 후보 도착 화면: 위저드 요청 → 페이지 이동(모달 아님) → 생성 중 표시 → 후보 카드 1..N + 직접 입력.
  LLM 대기는 페이지에서 SSE로 받는 구조의 자리 (목업은 타이머로 흉내).
